# Quiz de Futebol Brasileiro ⚽

Quiz interativo sobre futebol brasileiro, com design moderno e responsivo.

🔗 **Jogue agora:** https://dariokavalkeviski.github.io/Quiz/

## Funcionalidades

- 8 perguntas sobre o futebol brasileiro
- Feedback imediato (resposta certa em verde, errada em vermelho)
- Barra de progresso e placar ao vivo
- Tela de resultado com mensagem de desempenho
- Botão **Reiniciar Quiz** para jogar de novo
- Página de [gabarito](gabarito.html) com todas as respostas

## Tecnologias

- HTML5, CSS3 e JavaScript puro (sem dependências)
- Publicado automaticamente no GitHub Pages via GitHub Actions
